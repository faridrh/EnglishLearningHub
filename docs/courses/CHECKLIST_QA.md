# QA checklist — course lessons

Use for every new lesson (Danish / German / English).

## Page structure
- [ ] Practice section is **above** lesson content
- [ ] Jump links work: Practice / Learn / Speaking
- [ ] Goal is visible in header
- [ ] “Back to Practice” appears under content

## Interactive practice
- [ ] At least one listen step works (click → audio)
- [ ] Progress counter increments and shows ✓ when complete
- [ ] Practiced items get green / “is-practiced” style
- [ ] Sentence builder preview updates while typing
- [ ] Build & Hear speaks a complete, grammatical sentence
- [ ] Empty fields show helpful error message
- [ ] Drag-drop (if any): place all items, Check, Reset

## Language
- [ ] TTS locale correct (`da-DK` / `de-DE` / `en-US`)
- [ ] Labels and examples are in the right language
- [ ] Special letters display correctly (ÆØÅ / ÄÖÜß)

## Navigation
- [ ] Lesson N → Next opens N+1
- [ ] Back opens N−1
- [ ] Link to level index works
- [ ] Last lesson CTA is correct (next level / test / hub)

## Mobile
- [ ] No horizontal scroll
- [ ] Buttons tappable (min ~44px)
- [ ] Grid of letters/numbers wraps cleanly
- [ ] Forms stack vertically on narrow screens

## SEO / meta
- [ ] Unique title per lesson
- [ ] Meta description includes level + goal idea
- [ ] Canonical/permalink stable (`…/lesson-3/`)

## Content quality
- [ ] 6–10 listen items per step (rough guide)
- [ ] 2–3 speaking tasks
- [ ] Examples use high-frequency vocabulary
- [ ] No broken HTML in `content[].text`
