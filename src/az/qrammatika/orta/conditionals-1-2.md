# Şərt cümlələri: 1 və 2-ci növ

Şərt cümlələri bir vəziyyətin nəticəsini ifadə edir. Adətən iki hissədən ibarət olur: **if** ilə başlayan şərt hissəsi və nəticə hissəsi.

### 1-ci növ şərt cümləsi: real gələcək ehtimalı

Gələcəkdə baş verməsi mümkün olan vəziyyətlər üçün işlədilir.

**If + Present Simple, will + felin əsas forması**

- If it rains, we **will stay** at home. — Yağış yağsa, evdə qalacağıq.
- If you **study**, you **will pass** the exam. — Oxusanız, imtahandan keçəcəksiniz.

`if` hissəsində adətən **will** işlədilmir:

- Səhv: If it **will rain**, ...
- Düzgün: If it **rains**, ...

### 2-ci növ şərt cümləsi: qeyri-real və ya az ehtimallı vəziyyət

İndiki zaman və ya gələcəklə bağlı xəyal, məsləhət və az ehtimallı vəziyyət üçün işlədilir.

**If + Past Simple, would + felin əsas forması**

- If I **had** more time, I **would learn** Spanish. — Daha çox vaxtım olsaydı, ispan dili öyrənərdim.
- She **would travel** more if she **earned** more money. — Daha çox pul qazansaydı, daha çox səyahət edərdi.

`be` feli ilə formal İngilis dilində bütün şəxslərdən sonra **were** işlənə bilər:

- If I **were** you, I would accept the offer. — Mən sənin yerində olsaydım, təklifi qəbul edərdim.

### Söz sırası və durğu işarəsi

`if` hissəsi əvvəl gəldikdə iki hissə arasında vergül yazılır. Nəticə əvvəl gəldikdə vergül lazım deyil.

- If you call me, I will help you.
- I will help you if you call me.

### Tez-tez edilən səhvlər

1. 1-ci növdə `if`-dən sonra `will` işlətmək.
2. 2-ci növdə `would`-u hər iki hissədə işlətmək: **If I would have** deyil, **If I had**.
3. 2-ci növü real, planlaşdırılmış gələcək hadisə üçün işlətmək.
