# Cəm isimlər

Cəm isimlər birdən çox şəxsi, yeri, əşyanı və ya anlayışı bildirmək üçün işlədilir. İngilis dilində isimlərin cəm formasını düzgün düzəltmək başlanğıc səviyyədə vacib bacarıqlardan biridir.

### Qaydalı cəm isimlər

İngilis dilində əksər isimlərin cəm forması tək formaya **-s** şəkilçisi artırmaqla düzəlir.

### Qaydalı cəm formalarının əsas qaydaları

1. **Əksər isimlərə -s artırılır**
   - book → books
   - dog → dogs
   - pen → pens
   - girl → girls
   - boy → boys

2. **-s, -ss, -sh, -ch, -x və ya -z ilə bitən isimlərə -es artırılır**
   - bus → buses
   - glass → glasses
   - brush → brushes
   - watch → watches
   - box → boxes
   - quiz → quizzes

3. **Samit + y ilə bitən isimlərdə y hərfi i ilə əvəz olunur və -es artırılır**
   - baby → babies
   - city → cities
   - story → stories
   - country → countries
   - family → families

4. **Sait + y ilə bitən isimlərə yalnız -s artırılır**
   - boy → boys
   - day → days
   - key → keys
   - toy → toys
   - monkey → monkeys

5. **-f və ya -fe ilə bitən bir çox isimdə f hərfi v ilə əvəz olunur və -es artırılır**
   - wife → wives
   - life → lives
   - half → halves
   - shelf → shelves
   - wolf → wolves

   **İstisnalar:**
   - roof → roofs
   - belief → beliefs
   - chief → chiefs

6. **-o ilə bitən bir çox ismə -es artırılır**
   - potato → potatoes
   - tomato → tomatoes
   - hero → heroes
   - echo → echoes

   **Yalnız -s qəbul edən istisnalar:**
   - photo → photos
   - piano → pianos
   - radio → radios
   - zoo → zoos

### Qaydasız cəm isimlər

Bəzi isimlər cəm formasını ümumi qaydalarla düzəltmir. Bu formalar **qaydasız cəm isimlər** adlanır və onları ayrıca yadda saxlamaq lazımdır.

### Geniş yayılmış qaydasız cəm formaları

1. **Saitin dəyişməsi**
   - man → men
   - woman → women
   - foot → feet
   - tooth → teeth
   - goose → geese
   - mouse → mice

2. **-en sonluğu qəbul edən isimlər**
   - child → children
   - ox → oxen

3. **Tək və cəm forması eyni olan isimlər**
   - sheep → sheep
   - deer → deer
   - fish → fish (*fishes* müxtəlif balıq növlərini bildirərkən işlənə bilər)
   - species → species
   - aircraft → aircraft
   - series → series

4. **Cəm forması tamamilə dəyişən isimlər**
   - person → people
   - penny → pence (Britaniya pul vahidi haqqında danışarkən)

5. **Latın və yunan mənşəli cəm formaları**
   - analysis → analyses
   - crisis → crises
   - phenomenon → phenomena
   - criterion → criteria
   - datum → data
   - medium → media
   - curriculum → curricula
   - syllabus → syllabi / syllabuses

6. **Mürəkkəb isimlər**

   Adətən mürəkkəb ismin əsas hissəsi cəmlənir:
   - mother-in-law → mothers-in-law
   - passer-by → passers-by
   - editor-in-chief → editors-in-chief

   Mürəkkəb sözdə ayrıca isim yoxdursa, sonuna **-s** artırılır:
   - breakdown → breakdowns
   - check-in → check-ins
   - grown-up → grown-ups

### Sayılmayan isimlər

İngilis dilində bəzi isimlər sayılmır və cəm formaya malik olmur. Bu isimlər qrammatik baxımdan tək isim kimi qəbul edilir.

### Geniş yayılmış sayılmayan isimlər

1. **Mayelər və maddələr**
   - water, milk, coffee, tea, oil, gas
   - air, smoke, pollution

2. **Qida məhsulları**
   - bread, butter, cheese, meat, rice, sugar

3. **Mücərrəd anlayışlar**
   - advice, information, knowledge, news
   - education, homework, work, research
   - fun, happiness, health, love, music

4. **Fəaliyyətlər və idman növləri**
   - soccer, tennis, swimming
   - shopping, traveling

### Sayılmayan isimlərlə miqdar bildirmək

Sayılmayan isimlərin miqdarını ifadə etmək üçün ölçü və miqdar sözlərindən istifadə olunur:

- a piece of advice, two pieces of information
- a bottle of water, three cups of coffee
- a loaf of bread, two slices of cheese
- a bit of fun, a lot of happiness

### Xüsusi hallarda tək və cəm formalar

1. **Toplu isimlər** qrupun bütöv vahid və ya ayrı-ayrı üzvlər kimi qəbul edilməsindən asılı olaraq tək və ya cəm xəbərlə işlənə bilər:
   - The team **is** winning the championship. (Komanda vahid qrup kimi nəzərdə tutulur.)
   - The team **are** wearing their new uniforms. (Komanda üzvləri ayrı-ayrılıqda nəzərdə tutulur; bu forma Britaniya ingiliscəsində geniş yayılıb.)

2. **Əsər adları** cəm formada görünsə də, adətən tək xəbərlə işlənir:
   - "Great Expectations" **is** a novel by Charles Dickens.
   - "The Simpsons" **is** my favorite TV show.

3. **-s ilə bitən bəzi isimlər** cəm kimi görünsə də, tək xəbərlə işlənir:
   - Mathematics **is** my favorite subject.
   - The news **is** on at 6 PM.
   - Physics **involves** the study of matter and energy.

### Kontekstdə nümunələr

- There are five **books** on the table. — Masanın üzərində beş kitab var.
- Two **children** are playing in the park. — Parkda iki uşaq oynayır.
- I need to buy new **shoes**. — Mən yeni ayaqqabı almalıyam.
- My **teeth** are very sensitive to cold. — Dişlərim soyuğa çox həssasdır.
- The **women** in my family are all teachers. — Ailəmdəki qadınların hamısı müəllimdir.
- The **information** you gave me was very helpful. — Verdiyiniz məlumat çox faydalı idi. (*Information* sayılmayan isimdir.)
- I need three **loaves** of bread for the party. — Məclis üçün üç ədəd çörək lazımdır.

<script>
function checkPluralNounsAnswersAz() {
  const exercise = document.getElementById('plural-nouns-exercise-az');
  const inputs = exercise.querySelectorAll('.fill-blank');
  const results = document.getElementById('plural-nouns-exercise-az-results');
  const score = document.getElementById('plural-nouns-exercise-az-score');
  const feedback = document.getElementById('plural-nouns-exercise-az-feedback');
  let correct = 0;
  const messages = [];

  inputs.forEach((input, index) => {
    const answer = input.value.trim().toLowerCase();
    const expected = input.dataset.answer.toLowerCase();
    const isCorrect = answer === expected;

    input.classList.toggle('correct', isCorrect);
    input.classList.toggle('incorrect', !isCorrect);

    if (isCorrect) {
      correct += 1;
    } else {
      messages.push(`<p><strong>${index + 1}-ci sual:</strong> Düzgün cavab: ${input.dataset.answer}</p>`);
    }
  });

  results.hidden = false;
  score.textContent = `Nəticə: ${correct}/${inputs.length} (${Math.round(correct / inputs.length * 100)}%)`;
  feedback.innerHTML = correct === inputs.length
    ? '<p class="exercise-success">Əla! Bütün cavablar doğrudur.</p>'
    : messages.join('');
}

function resetPluralNounsExerciseAz() {
  const exercise = document.getElementById('plural-nouns-exercise-az');
  exercise.querySelectorAll('.fill-blank').forEach(input => {
    input.value = '';
    input.classList.remove('correct', 'incorrect');
  });
  document.getElementById('plural-nouns-exercise-az-results').hidden = true;
}
</script>
